# AgroGuide BD

Flutter prototype for the AgroGuide BD Software Engineering project.

## Current scope
- Login / Register demo
- Home dashboard
- Crop advisory
- Fertilizer recommendation demo
- Pest/disease information and image-upload placeholder
- Market price information
- Weather information
- Community posts
- Expert question demo
- Helpline
- Feedback/reporting
- Profile
- Local/mock data only (no backend)

## Run
```bash
flutter pub get
flutter run
```

## Important
This version is a frontend prototype. Real OTP, authentication, image upload, live weather, live market prices, database storage, expert queue and notifications require a backend/API or Firebase integration.
